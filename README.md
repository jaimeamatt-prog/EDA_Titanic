# 🚢 Titanic · Análisis exploratorio de datos

**Python · pandas · NumPy · Seaborn · SciPy · scikit-learn**

Proyecto académico para estudiar qué características de los pasajeros están relacionadas con la supervivencia en el Titanic.

## 🔎 ¿Qué incluye?

- Exploración y visualización de datos.
- Análisis de diez hipótesis sobre la supervivencia.
- Pruebas estadísticas e interpretación de resultados.
- Limpieza y preparación de datos.

## 📂 Estructura del proyecto

| Archivo o carpeta | Contenido |
|---|---|
| `01_EDA.ipynb` | Exploración, hipótesis y conclusiones |
| `02_Preprocessing.ipynb` | Limpieza y transformación |
| `00_Data/Raw/` | Datos originales |
| `00_Data/Cleaned/` | Datos procesados |
| `requirements.txt` | Dependencias |

## 📊 Resultados destacados

- **74,20 %** de supervivencia entre las mujeres, frente al **18,89 %** entre los hombres.
- **62,96 %** en primera clase, frente al **24,24 %** en tercera.
- Las familias de **2 a 4 personas** presentaron una supervivencia del **57,88 %**.

> Los resultados muestran asociaciones, no causalidad. Las hipótesis sobre billetes compartidos e interacciones se analizaron de forma descriptiva.

## 🚀 Cómo ejecutarlo

1. Clona o descarga el repositorio.
2. Instala las dependencias con `python -m pip install -r requirements.txt`.
3. Abre la carpeta en VS Code o Jupyter y selecciona el entorno de Python.
4. Ejecuta los notebooks en orden, manteniendo la estructura de carpetas.
